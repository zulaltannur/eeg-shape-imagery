# Stage 29: manuscript figures

Each script writes one or more figures to `figures/` (300 dpi PNG). Run from this folder, e.g. `python fig2_generation.py`.

| Script | Output |
|---|---|
| fig1_design.py | Figure 1: shapes, geometric distances, trial timelines |
| fig2_generation.py | Figure 2: shapes generated from EEG, final system, four conditions |
| fig3_4.py | Figure 3: confusion matrices; Figure 4: vision groups and training source |
| fig5_group_shapes.py | Figure 5: congenitally low vision, own-group vs sighted pattern |
| fig6_time_frequency.py | Figure 6: time windows and frequency bands |
| fig7_S5_regions.py | Figure 7: double dissociation, occipital alpha during touch; Figure S5 |
| fig8_mantel_occipital.py | Figure 8: visual experience (Mantel), occipital alpha second by second |
| fig9_word_networks.py | Figure 9: hearing the word, regional co-variation |
| figS1_S2.py | Figures S1 (THINGS-EEG2 encoder), S2 (searchlight) |
| figS3_person_tables.py | Figures S3 (per-person shape tables, `figures/S3/`) |
| figS4_ranking.py | Figure S4 (person ranking map) |
| figS6_tried_methods.py | Figure S6 (approaches that did not exceed chance) |

Participants appear only as anonymous labels: P01–P23 in English, K01–K23 in Turkish, same number in both languages.
